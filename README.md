# Bitcoin Price Prediction using Machine Learning

This project demonstrates an end-to-end machine learning pipeline for predicting
Bitcoin prices using historical market data and live price fetched via an API.

## Features
- Historical Bitcoin price analysis
- Linear Regression model
- Live Bitcoin price fetching using CoinGecko API
- Future price prediction

## Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- yfinance
- CoinGecko API

## How to Run
1. Open the Jupyter Notebook
2. Run all cells from top to bottom
3. View the live price prediction output
